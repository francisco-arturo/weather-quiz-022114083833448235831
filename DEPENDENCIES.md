# Dependencies and third-party assets

## Runtime dependencies

**None.** The browser app is plain HTML, CSS and ES modules. It runs directly from any static file host. There is no package manager install, no build pipeline and no runtime framework.

## Development dependencies

| Tool | Version used | Licence | Purpose |
|---|---|---|---|
| Node.js | 18 or newer | MIT | Local static server and built-in test runner only. Not shipped to the browser. |
| Modern web browser | Current Chrome, Edge, Firefox or Safari | Browser vendor licence | Runs the app |

Node.js is not bundled with the deliverable. Any environment that can serve static files can host the app.

## Fonts

No webfonts are downloaded or bundled. The design uses the operating system's UI sans-serif and serif families through CSS font stacks. No font licence is redistributed with this project.

## Images and icons

- All icons, the logo and the decorative contour map are **original inline SVG** written for this prototype.
- There is no stock photography, icon-font, illustration pack or third-party image.
- No third-party icon licence or attribution is required.

## Code and content

- Application code, styles and markup were written for this brief.
- Quiz copy was drafted for the prototype. The student team will supply or approve the final English content.
- Official guidance pages are **linked**, not copied into the repository. Their content remains the property of the respective Swiss federal offices.

## External services

None at runtime. The app makes no API calls, loads no remote script, sets no cookies and sends no analytics.

## Licence position

No third-party package or asset is redistributed, so there are no third-party licence obligations to carry into the client handover. Ownership and licensing of the delivered source code can be agreed directly with the client.
